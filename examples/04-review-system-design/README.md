# Example 4: Review System Design

**Skill**: [system-design-reviewer](../../skills/system-design-reviewer/)

## Try it

Ask an agent with `system-design-reviewer` installed:

> "Review this design: single Postgres instance holds (short_code,
> long_url); short codes generated by hashing the long URL and taking the
> first 7 base62 characters; no caching layer; single app server behind a
> load balancer; redirect endpoint reads Postgres on every request."

## What a correct run produces

`SYSTEM_DESIGN_REVIEW.md` with an executive summary, stated assumptions
(no scale target was given above — a correct run should say so), critical
risks, failure scenarios, bottlenecks, and prioritized recommendations.

## Reference answer

[`skills/system-design-reviewer/examples/url-shortener-review.md`](../../skills/system-design-reviewer/examples/url-shortener-review.md)
reviews this exact design — it should independently surface both the
hash-collision handling gap and the missing cache layer.
